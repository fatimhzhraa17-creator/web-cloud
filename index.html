Apa itu Cloud Computing?

Cloud computing adalah layanan penyimpanan dan komputasi melalui internet tanpa harus menggunakan perangkat lokal.

Model Layanan

  • IaaS (Infrastructure as a Service)
  • PaaS (Platform as a Service)
  • SaaS (Software as a Service)

Keunggulan

  • Hemat biaya
  • Fleksibel
  • Bisa diakses dimana saja
